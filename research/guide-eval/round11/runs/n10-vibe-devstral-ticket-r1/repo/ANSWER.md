# Prisma ORM Setup Summary

## What I Did

1. **Initialized Prisma 8 (current npm version)**: Used `npx prisma@latest orm init --yes --target postgres --authoring psl` to set up Prisma ORM with the current version from npm (8.0.0-rc.33).

2. **Updated the data model**: Modified `src/prisma/contract.prisma` to match requirements:
   - User: id (autoincrement), email (unique), name (optional)
   - Post: id (autoincrement), title, content (optional), published (default false), author (relation to User), authorId

3. **Emitted the contract**: Ran `npx prisma contract emit` to generate TypeScript types in `src/prisma/contract.json` and `src/prisma/contract.d.ts`.

4. **Created database tables**: Ran `npx prisma db init` to create the User and Post tables in the PostgreSQL database.

5. **Created script.ts**: Added a TypeScript script at the project root that:
   - Creates a user with email 'alice@example.com' and name 'Alice'
   - Creates two posts for that user (one published, one not)
   - Queries and prints all users with their posts using `include('posts')`
   - Runs with `npx tsx script.ts`
