# Prisma setup

Installed Prisma ORM 7.10.1, the current matching npm release of Prisma Client and its PostgreSQL adapter. The `prisma` CLI's npm `latest` tag currently points to an 8.0 release candidate, so the CLI is pinned to the matching 7.10.1 version.

Defined `User` and `Post` in `prisma/schema.prisma`. Users have a unique email and optional name. Posts have a title, optional content, a `published` flag defaulting to `false`, and one required author. The migration in `prisma/migrations` was applied to the local PostgreSQL database from `.env`.

`script.ts` creates a user with two posts and prints all users with their posts. It uses a unique sample email on each run, so it can be run repeatedly:

```sh
npx tsx script.ts
```

The generated Prisma client is excluded from Git and is regenerated by `npm install`. I verified `npx prisma generate`, `npx tsx script.ts`, and `npx tsc --noEmit` successfully.
