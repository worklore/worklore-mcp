**Cause**

The `related` function stored raw similarity scores as Python `float` values in the
DynamoDB `similar` attribute. DynamoDB rejects floats—only `Decimal` or integer
types are allowed. The first publish succeeded because the table was empty,
so no scores were written. Subsequent publishes attempted to write a dict with a
`float` `score` and raised:

```
TypeError: Float types are not supported. Use Decimal types instead.
```

**Fix**

Convert the similarity value to an integer percentage before storing it. The
updated `related` function multiplies the float (0‑1) by 100, rounds it, and stores
the resulting integer in the `score` field. This satisfies DynamoDB’s type
requirements while preserving the relative ordering of similarity scores.

  path hides it).
- Updated the write path to store integer percentages instead of floats.
- Added documentation/comments explaining the change.

All tests now pass.
