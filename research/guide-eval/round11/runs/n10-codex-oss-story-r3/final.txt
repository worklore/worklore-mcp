**What was done**

- Installed the current Prisma version (`prisma@latest`, 8.0.0‑rc.33) together with `@prisma/orm-postgres` and `dotenv`.
- Initialized Prisma ORM (ORM‑8 style) using `npx prisma@latest orm init --yes --target postgres --authoring psl`, creating `prisma` config and `src/prisma` contract files.
- Updated `src/prisma/contract.prisma`:
  - `User` with unique `email` and optional `name`.
  - `Post` with `title`, optional `content`, `published` defaulting to `false`, and a required `author` relation to `User`.
- Ran `npx prisma@latest contract emit` to generate `contract.json` and `contract.d.ts`.
- Executed `npx prisma@latest db init` to create the tables in the PostgreSQL database defined in `.env`.
- Added `script.ts` at the project root that:
  - Clears existing `User`/`Post` rows for idempotent runs.
  - Creates a user with two posts in a single call.
  - Retrieves and prints every user with their posts.
  - Closes the DB connection.
  - Runs with `npx tsx script.ts`.
