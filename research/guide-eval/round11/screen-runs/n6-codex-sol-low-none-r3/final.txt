Added the current npm release of the Hedera JavaScript SDK (`@hashgraph/sdk` 2.81.0) and wrote [src/transfer.ts](/tmp/h-JYDLBe/src/transfer.ts). `npx tsc --noEmit` passes. The script runs with the test values, and its output decodes to the requested transaction ID, node, memo, and a signature.
