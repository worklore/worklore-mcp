# Answer

## What was done

- Added the Hedera JavaScript SDK at the current npm version, pinned exactly: `@hashgraph/sdk@2.81.0` (`npm view @hashgraph/sdk version`). `package-lock.json` was generated by `npm install`.
- Added `src/transfer.ts`, run with `npx tsx src/transfer.ts`. It:
  - reads `OPERATOR_ID`, `OPERATOR_KEY` (DER-encoded ED25519 private key, hex), `RECIPIENT_ID` and `VALID_START` (Unix seconds) from the environment (loaded from `.env` via `dotenv`);
  - builds a `TransferTransaction` moving 1 hbar from the operator to the recipient, memo `invoice 42`, node account `0.0.3`, transaction ID `OPERATOR_ID@VALID_START`;
  - freezes it locally, signs it with the operator key, and prints only the signed transaction bytes as hex.
- No network calls are made: the transaction is frozen with an explicit node and transaction ID, so no client or node lookup is needed.
- Added `.gitignore` containing `node_modules/` so installed dependencies are not picked up by git.

## Verification

- `npx tsc --noEmit` passes with no errors.
- `npx tsx src/transfer.ts` runs and prints a hex string.
- Decoding that output offline with the SDK (`Transaction.fromBytes`) gives:
  - memo: `invoice 42`
  - transaction ID: `0.0.1001@1793000000.000000000`
  - node: `0.0.3`
  - transfers: `0.0.1001 = -1 ℏ`, `0.0.1002 = +1 ℏ`
  - one signature present

## Choices made

- The SDK version is pinned exactly (no `^`), so the transaction format does not change under future installs.
- `VALID_START` is parsed as a Unix timestamp in seconds; non-integer or negative values abort with an error.
- The script aborts with a clear message if any required environment variable is missing.

## Notes

- `.env` is tracked in git and contains an `OPERATOR_KEY` value. Even though the values are test values, committing private keys is risky; consider moving `.env` into `.gitignore` and rotating any real key that has been committed. I did not change this.
- `README.md` says a separate service submits the transactions. This script does not submit anything, which matches that design.
