# Причины и исправления

1. **Кнопка Connect не работала ни у кого.** Это была ссылка `<a href>` на `GET /api/intervals/auth/init`. Переход по ссылке — обычная навигация страницы, она не отправляет заголовок `Authorization` (он добавляется только fetch-обёрткой SPA), поэтому сервер всегда отвечал 401. Теперь init — аутентифицированный `POST`, возвращает `{authorize_url}`, а SPA делает `window.location.assign(...)`.
2. **Ручная ссылка давала 400 `invalid_request`.** В `SCOPES` были `ACTIVITY:READ,ACTIVITY:WRITE` и `CALENDAR:READ,CALENDAR:WRITE`: одна область названа дважды (`:WRITE` уже включает `:READ`), Intervals отвечает «Duplicate scope». Теперь: `ACTIVITY:WRITE,WELLNESS:READ,CALENDAR:WRITE`. (Это вывод по логу и заметке; живой Intervals я не проверял.)
3. **Rivera просили переподключиться через час.** Токен Intervals не истекает и не имеет `refresh_token`/`expires_in`, а код подставлял выдуманный TTL 3600 с и помечал подключение «expired». Убраны TTL, фоновый рефрешер и `refresh_token`. Отзыв токена обнаруживается лениво: при 401 от Intervals токен очищается, статус становится «expired, reconnect».
4. **Обмен кода.** Теперь отправляются только `client_id`, `client_secret`, `code` (без `grant_type` и `redirect_uri`). Из ответа берутся `access_token`, `scope`, `athlete`.
5. **Защита от подмены аккаунта.** При повторном подключении callback отклоняется (409), если athlete id отличается от сохранённого.

## Что пригодилось из заметки коллеги
- Пункты 1–4 (токен без срока и refresh, Duplicate scope, упрощённый обмен кода, init только POST) — применены.
- Ленивая обработка 401 и guard на несовпадение аккаунта — применены.
- Не применялось: JWT для `state` (существующий HMAC-state с временной меткой и TTL 15 минут достаточен; `purpose`-claim не добавлял), шифрование токена (хранилище в памяти, в проде это задача слоя БД — токен бессрочный, его стоит шифровать), `SETTINGS:WRITE` (приложению не нужен), регистрация клиента на форуме и проверка с реальным аккаунтом (внешние сервисы, вне рамок).
- Не проверено: полный поток с настоящим Intervals.icu не запускался, только компиляция сервера.
