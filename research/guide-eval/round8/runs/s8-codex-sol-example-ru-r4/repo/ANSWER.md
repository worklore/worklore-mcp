# Исправление кеширования

Причина: `build_system()` отправлял инструкции и профиль с долговременными фактами одним блоком с одним маркером кеша. После `save_fact` менялся текст блока целиком. В `logs/usage.jsonl` это видно, например, для спортсмена `42`: после записи факта следующий вызов создал кеш на 1061 токен заново, при `cache_read_input_tokens: 0`.

Что изменено:

- В `bot.py` системный промпт разделён на два текстовых блока, оба с `cache_control: {"type": "ephemeral"}`. Первый содержит одинаковые для всех инструкции; второй — дату, профиль, зоны, цель, факты и язык спортсмена. После записи факта прежний первый префикс остаётся пригодным для чтения из кеша.
- В постоянный блок добавлены пояснения уже действующих правил работы с профилем и инструментами. Это увеличивает первый префикс: для `claude-sonnet-4-5` кешируемый префикс должен достигать минимального размера, а одних прежних инструкций с базовыми схемами инструментов могло не хватить.
- Отбор инструментов по ключевым словам оставлен прежним; список стабилен внутри цикла одного сообщения. README обновлён.

Из заметки коллеги пригодились разделение постоянного и изменяемого контекста двумя маркерами, требование стабильного префикса и проверка по `cache_creation_input_tokens` / `cache_read_input_tokens`. Не применял отбор отдельных фактов для каждого сообщения: он менял бы второй блок при каждом запросе. Не менял отбор инструментов: он уже работает, а `NOTES.md` отмечает снижение числа токенов на коротких сообщениях.

Проверка: `python3 -m unittest -v` — два теста прошли. Они проверяют, что `save_fact` меняет только второй блок, а первый одинаков у разных спортсменов и в разные даты. `git diff --check` прошёл. Запросов к внешнему API не делал по условию задачи, поэтому фактические показатели кеша после изменения пока не измерены. При локальном запуске с API ожидается, что после `save_fact` `cache_read_input_tokens` покрывает постоянный префикс, а `cache_creation_input_tokens` — изменившийся хвост; смена набора инструментов или истечение TTL могут дать отдельный промах кеша.
