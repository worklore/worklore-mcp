# Исправление генератора пульсовых коридоров

## Что было изменено и почему

В файле [gen.py](file:///tmp/h-DFlxbP/gen.py) в функции `hr_target` ключ нижней границы пульсового диапазона был изменён с `"value"` на `"start"`:

```python
# Было:
return {"units": "%lthr", "value": lo, "end": hi}

# Стало:
return {"units": "%lthr", "start": lo, "end": hi}
```

### Причина
При экспорте тренировки из Intervals.icu в формат Garmin FIT логика трансляции определяется именами ключей в объекте цели:
- Структура `{"value": lo, "end": hi}` интерпретируется как цель **Lap-HR / по зонам**. В этом режиме Garmin при синхронизации сопоставляет и обрезает границы диапазона под свои локальные автоопределённые пульсовые зоны (как зафиксировано в [readback/watch-notes.md](file:///tmp/h-DFlxbP/readback/watch-notes.md)).
- Структура `{"start": lo, "end": hi}` переключает режим в **Instant-HR коридор**. В этом случае Intervals.icu вычисляет точные значения bpm на основе сохранённого LTHR атлета (172 bpm) и передаёт их напрямую в FIT, не привязываясь к зонам часов.

---

## Какие части заметки пригодились, а какие были пропущены

### Пригодилось:
- **Ключевой инсайт про имя поля `start` вместо `value`:** именно замена ключа `value` на `start` при сохранении `units: "%lthr"` переключает Intervals.icu с зонального режима на точный коридор Instant-HR.
- **Подтверждение поведения неудачных попыток:** описание проблем с `units: "bpm"` (некорректное масштабирование процентов в FIT) и `start_bpm`/`end_bpm` (отбрасывание неподдерживаемых полей) помогло убедиться в точности диагноза проблемы, описанной в [readback/watch-notes.md](file:///tmp/h-DFlxbP/readback/watch-notes.md).

### Пропущено (не потребовалось):
- **Секция про текстовое поле `description` и парсер Intervals:** текущий генератор формирует структурированный JSON через `workout_doc.steps`, а не текстовое описание шагов в грамматике Intervals.icu.
- **Инструкции по настройке окружения и шаги воспроизведения через API/Garmin Connect:** токены доступа, API-запросы (`POST /api/v1/athlete/{id}/events`) и физическая синхронизация с часами, так как работа велась исключительно локально в кодовой базе генератора без отправки данных во внешние сервисы.
