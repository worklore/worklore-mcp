# Причина и исправление

Первая публикация проходила, потому что в пустой библиотеке поле `similar` было пустым. При второй публикации `related()` добавляла туда `score`, который `similarity()` вычисляла как `float`. Сериализатор boto3/DynamoDB не поддерживает `float` даже внутри вложенного списка, поэтому `put_item()` выбрасывал `TypeError: Float types are not supported. Use Decimal types instead.`, а обработчик отвечал 500.

Теперь `related()` преобразует каждый балл в `Decimal` до записи. `Decimal(str(...))` сохраняет округлённое десятичное значение без двоичного артефакта `float`. Добавлен тест двух последовательных запросов через `handler()`: оба возвращают 201, а сохранённый балл похожей истории имеет тип `Decimal`.

Проверка: `python3 -m unittest discover tests` — 2 теста прошли.
