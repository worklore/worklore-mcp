# Почему вторая публикация возвращала 500

При первой публикации библиотека пуста, поэтому поле `similar` записывается как пустой список. При следующей публикации `related()` добавляет в него оценку сходства `score`. Функция `similarity()` возвращала Python `float`, а сериализатор boto3 для DynamoDB не принимает `float`. Поэтому `table.put_item()` выбрасывал `TypeError: Float types are not supported. Use Decimal types instead.`, который обработчик превращал в HTTP 500.

# Исправление

`similarity()` теперь возвращает `Decimal` с прежним округлением до четырёх знаков. Все создаваемые оценки в `similar` поэтому имеют тип, который принимает DynamoDB, включая оценки при последующих публикациях. Добавлен тест трёх последовательных запросов через обработчик: он проверяет ответы 201, сохранение материалов и тип оценок в записанных элементах.

Проверка: `python3 -m unittest discover tests -v` — 2 теста прошли.
