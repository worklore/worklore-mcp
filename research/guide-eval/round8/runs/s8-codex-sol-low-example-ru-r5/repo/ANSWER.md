# Исправление кеширования

В `bot.py` функция `build_system` теперь возвращает два текстовых блока с отдельными `cache_control: ephemeral`: неизменные инструкции и контекст спортсмена. После `save_fact` меняется только второй блок, поэтому первый остаётся тем же кешируемым префиксом. Порядок и состав инструментов не менял.

Локально проверил построение запроса до и после добавления факта: первый блок и инструменты совпадают, новый факт появляется только во втором блоке. Внешний API не вызывал, поэтому фактические значения `cache_read_input_tokens` и `cache_creation_input_tokens` после изменения не измерены.

Из заметки коллеги пригодились разделение статической и изменяемой частей двумя маркерами, сохранение стабильного списка инструментов в пределах сообщения и проверка счётчиков usage. Отбор фактов по релевантности и изменения фильтрации инструментов не применял: здесь они не нужны для исправления причины сброса кеша.
