# Исправление кеширования

В `bot.py` разделил системный промпт на два текстовых блока. Постоянные инструкции стоят первыми и помечены `cache_control: ephemeral`; профиль, дата и долговременные факты идут следом без метки. Поэтому `save_fact` обновляет доступный модели контекст в следующем раунде, но не меняет кешируемый префикс. Добавил постоянные пояснения к существующим правилам, чтобы этот префикс оставался достаточно большим для кеширования.

Набор инструментов по ключевым словам не менял. Если набор выбранных инструментов меняется между сообщениями, кеш для нового префикса инструментов всё ещё создаётся заново.

Обновил описание в `README.md`. Добавил локальные проверки: неизменность кешируемого блока после `save_fact`, появление нового факта в следующем раунде и независимость кешируемого блока от даты и фактов. `python3 -m unittest -v test_bot` — 2 проверки прошли. Внешний API не вызывал; фактические счётчики `usage` после исправления локально не измерялись.
