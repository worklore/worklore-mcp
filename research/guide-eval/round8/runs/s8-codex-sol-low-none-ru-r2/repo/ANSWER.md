# Исправление кеширования

- Разделил системный промпт на два блока: постоянные инструкции и меняющийся контекст спортсмена. У каждого блока свой `cache_control`. После `save_fact` меняется только второй блок, поэтому первый может читаться из кеша.
- Добавил в постоянный блок пояснения уже действующих правил работы с профилем и инструментами, чтобы его размер оставался достаточным для отдельного кеширования.
- Выбор инструментов по ключевым словам не менял.

Проверил локально: после добавления факта первый блок запроса остаётся побайтно тем же, второй меняется, выбор инструментов сохраняется. `python3 -m py_compile bot.py` проходит. Фактические счётчики кеша требуют следующего вызова API; внешние сервисы не вызывались.
