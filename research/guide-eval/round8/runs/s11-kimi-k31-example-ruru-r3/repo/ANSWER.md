# Причина

`similarity()` в `src/app.py` вычисляет оценку через деление и `round()`, поэтому возвращает `float`. При первой публикации таблица пуста, `related()` возвращает пустой список `similar`, и в `put_item` не попадает ни одного `float`. При второй публикации в `similar` появляется запись с оценкой типа `float`. Сериализатор boto3 не поддерживает этот тип для DynamoDB и выбрасывает `TypeError: Float types are not supported. Use Decimal types instead.` Именно этот сбой записан в `logs/error.log`; общий обработчик исключений превращает его в ответ 500.

# Исправление

В `src/app.py` оценка преобразуется в `Decimal` через `Decimal(str(similarity(...)))` при формировании записи о похожей истории. `Decimal` поддерживается DynamoDB, а преобразование через строку сохраняет уже округлённое десятичное значение без двоичных артефактов `float`. Шкала оценки и точность остались прежними.

В `tests/test_publish.py` добавлен регрессионный тест двух последовательных публикаций через `handler()`: первая создаёт исходное состояние таблицы, вторая проходит ветку вычисления похожести. Тест проверяет ответы 201 и тип сохранённой оценки `Decimal`. `FakeTable` рекурсивно проверяет вложенные значения, поэтому возврат `float` в `similar` снова сломает тест.

Проверка: `python3 -m unittest discover tests` — 2 теста, успешно. Отдельное воспроизведение двух запросов также вернуло 201 для обеих публикаций.

# Что пригодилось из заметки коллеги

- Объяснение зависимости от состояния: пустая таблица скрывает ошибку, а вторая запись впервые выполняет код вычисления похожести.
- Рекомендация проследить результаты деления и округления до записи DynamoDB и преобразовать их в поддерживаемый числовой тип на границе записи.
- Идея регрессионного теста, который сначала заполняет таблицу, а затем проверяет следующую запись.

Переход на целые проценты не использован: он изменил бы формат хранимой оценки и снизил точность, тогда как `Decimal` устраняет причину без такого изменения. Публикация в реальную таблицу не выполнялась; локальный `FakeTable` специально воспроизводит проверку типов boto3.
