# Исправление кеширования

- Разделил системный промпт на два блока: неизменные правила с `cache_control: ephemeral` и данные спортсмена без маркера кеша. После `save_fact` меняется только второй блок, поэтому правила остаются доступными как прежний кешированный префикс.
- Уточнил постоянные правила работы с профилем и фактами. Это также оставляет неизменный префикс выше минимального размера, нужного для кеширования Claude при обычном наборе инструментов.
- Сохранил существующий выбор инструментов по ключевым словам. Смена набора инструментов или истечение срока кеша всё ещё может вызвать создание нового префикса.
- Добавил проверку двух раундов с `save_fact`: новый факт виден во втором запросе, а кешируемый блок совпадает. `python3 -m unittest -v test_bot` — 2 теста прошли.

Реальную статистику токенов после изменения не измерял: запросы к внешнему API запрещены условиями задачи.
