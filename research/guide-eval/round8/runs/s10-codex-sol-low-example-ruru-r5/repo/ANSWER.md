# Реализация аналитики

Добавлены все шесть событий из `docs/EVENTS.md` через существующую обёртку `Analytics.capture`:

- На экране регистрации `registration_email_started` и `registration_phone_started` отправляются при первом вводе непустого значения, по одному разу за жизнь экрана. Email и телефон в свойства не попадают.
- `loan_amount_changed` отправляется после завершения перемещения слайдера с целочисленным `amount`.
- `terms_accepted` отправляется при установке флажка.
- `registration_continue_tapped` отправляется при нажатии доступной кнопки с `amount` (int) и `terms` (bool).
- На экране предложений `offers_scrolled` отправляется после окончания прокрутки списка с `offset` (double). Событие не отправляется при отсутствии смещения.

Из заметки коллеги пригодились ограничение событий ввода одним срабатыванием за посещение экрана, перенос события слайдера на `onChangeEnd` и отслеживание завершения прокрутки вместо каждого обновления. Имена событий и свойства оставлены согласно спецификации.

Проверка: `flutter analyze` — ошибок нет. Отправка событий в PostHog не проверялась.
