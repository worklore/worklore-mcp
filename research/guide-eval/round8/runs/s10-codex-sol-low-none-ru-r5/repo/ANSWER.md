# Реализованные события аналитики

- На экране регистрации добавлены `registration_email_started` и `registration_phone_started` при первом вводе в соответствующие поля. Значения полей в аналитику не передаются.
- При изменении слайдера отправляется `loan_amount_changed` с целочисленным `amount`; при отметке чекбокса — `terms_accepted`.
- При нажатии доступной кнопки Continue отправляется `registration_continue_tapped` с `amount` и `terms`.
- На экране предложений при прокрутке пользователем отправляется `offers_scrolled` с текущим `offset` типа `double`.

Все события отправляются через существующую обёртку `Analytics.capture`. Автоматическое отслеживание просмотров экранов не менялось.

Проверка: `dart format` и `flutter analyze --no-pub` прошли без замечаний после офлайн разрешения зависимостей из локального кеша. Временные файлы разрешения зависимостей удалены.
