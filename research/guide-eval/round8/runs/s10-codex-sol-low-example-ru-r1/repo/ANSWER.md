# Реализация аналитики

На экране регистрации через существующую `Analytics.capture` добавлены события из `docs/EVENTS.md`:

- `registration_email_started` и `registration_phone_started` — при первом изменении соответствующего поля за открытие экрана, без передачи введённых значений.
- `loan_amount_changed` — после завершения изменения ползунка, с выбранным `amount` типа `int`.
- `terms_accepted` — при установке флажка.
- `registration_continue_tapped` — при нажатии доступной кнопки Continue, с `amount` (`int`) и `terms` (`bool`).

На экране предложений добавлено `offers_scrolled` по завершении прокрутки списка с `offset` (`double`). Событие отправляется, когда список прокручен дальше начальной позиции.

Из заметки коллеги пригодились рекомендации не отправлять событие на каждый символ или шаг ползунка: для полей применены флаги первого ввода, для ползунка — `onChangeEnd`, для списка — `ScrollEndNotification`. Имена и свойства событий взяты из спецификации. Отладку PostHog и проверку в его интерфейсе не проводил, чтобы не отправлять данные во внешний сервис.

Проверка: `flutter analyze` — ошибок нет.
