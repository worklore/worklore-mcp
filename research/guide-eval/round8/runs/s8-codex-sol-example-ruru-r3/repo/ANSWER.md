# Исправление кеша промпта

В `bot.py` функция `build_system()` теперь передаёт Claude два текстовых блока с `cache_control: ephemeral`: неизменные `INSTRUCTIONS` и контекст спортсмена (дата, профиль, зоны, цель, факты, язык). После `save_fact` меняется только второй блок, поэтому статический префикс может читаться из кеша. Содержимое инструкций и контекста не менял.

Из заметки пригодились разделение по границе изменчивости и два маркера кеша. Также учёл, что порядок инструментов должен быть стабильным: существующий `select_tools()` сохраняет его и выбирает инструменты один раз на сообщение. Отбор фактов под каждое сообщение не добавлял — он сделал бы контекст непостоянным. Совет заменить текущую фильтрацию инструментов не применял: она уже есть и, по `NOTES.md`, снижает расход на простых сообщениях.

Проверил локально: после добавления факта первый блок остаётся идентичным, второй меняется; оба содержат маркер кеша. `python3 -m py_compile bot.py` проходит. Реальные показатели `cache_read_input_tokens` и `cache_creation_input_tokens` после правки не проверял: для этого нужен вызов внешнего API, а он запрещён условиями задачи.
