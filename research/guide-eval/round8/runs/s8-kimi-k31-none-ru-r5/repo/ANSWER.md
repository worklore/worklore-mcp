# Исправление кеширования

Причина: `build_system()` объединял статические инструкции и контекст атлета в один блок с `cache_control`. После `save_fact` менялся весь блок, поэтому прежний кеш становился непригоден и инструкции оплачивались повторно.

Изменения:
- В `bot.py` системный промпт разделён на два блока. Первый содержит только неизменные `INSTRUCTIONS` и сохраняет `cache_control: {"type": "ephemeral"}`.
- Контекст атлета, включая долговременные факты, вынесен во второй блок без кеширования. Теперь `save_fact` меняет только этот небольшой блок, а закешированный префикс остаётся байт-в-байт тем же.
- Описание поведения кеша обновлено в `README.md`.

Проверка: локально прогнан полный цикл `reply()` с подменным LLM и вызовом `save_fact`. В обоих раундах первый системный блок совпал полностью, новый факт появился только во втором блоке и был сохранён во временной копии данных. Внешние API не вызывались, реальные данные и логи не изменялись.
