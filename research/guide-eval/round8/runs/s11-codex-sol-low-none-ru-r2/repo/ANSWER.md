# Причина и исправление

Первая публикация проходит, потому что в пустой библиотеке поле `similar` равно `[]`. При следующей публикации `related()` добавляет оценку сходства, которую `similarity()` вычисляет как `float`. `boto3` не сериализует `float` в DynamoDB, поэтому `put_item()` выбрасывает `TypeError: Float types are not supported`, а обработчик возвращает 500.

В `related()` оценка теперь преобразуется в `Decimal` через строковое представление. Так сохраняется рассчитанное десятичное значение, а каждый элемент `similar` пригоден для записи через boto3. Добавлен тест, который публикует две истории через обработчик и проверяет успешный ответ и тип сохранённой оценки.

Проверка: `python3 -m unittest discover tests -v` — 2 теста прошли.
