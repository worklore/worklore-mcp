# Исправление кеширования

В `bot.py` разделил системный промпт на кешируемый префикс (инструкции и стабильный профиль спортсмена) и изменяемый блок (дата и долговременные факты). `save_fact` теперь меняет только блок после `cache_control`, поэтому при следующем вызове сохранённый факт виден модели, а статический префикс может читаться из кеша. Дополнил стабильные инструкции с учётом минимального размера кешируемого префикса. Выбор инструментов по ключевым словам сохранён; смена набора инструментов по-прежнему может создать отдельную запись кеша.

Проверил локально: после `save_fact` кешируемый блок остаётся побайтно прежним, блок фактов обновляется, в нём нет `cache_control`; `py_compile` и `git diff --check` прошли. Внешних API не вызывал, поэтому фактические значения `cache_read_input_tokens` после исправления не измерялись.
