# Причина

При первой публикации библиотека пуста, поэтому `related()` возвращает пустой список `similar`, и DynamoDB успешно сохраняет запись. При повторной публикации `related()` вычисляет сходство с уже существующей записью. Функция `similarity()` возвращает `float`, и этот тип попадает в `Item` как `similar[].score`.

DynamoDB через boto3 не поддерживает `float`: сериализатор требует `Decimal`. Поэтому `table.put_item()` выбрасывает `TypeError: Float types are not supported. Use Decimal types instead.`, а обработчик возвращает HTTP 500. Именно эта ошибка записана в `logs/error.log`.

# Исправление

В `src/app.py` оценка сходства преобразуется в `Decimal` через `Decimal(str(...))` перед добавлением в `similar`. Таким образом, в DynamoDB передаются только поддерживаемые числовые типы, а вычисление и округление оценки остаются прежними.

В `tests/test_publish.py` добавлен регрессионный тест: он выполняет две последовательные публикации через `handler()`, проверяет, что обе возвращают 201, обе записи сохранены, а оценка сходства имеет тип `Decimal`.

Проверка: `python3 -m unittest discover tests` — 2 теста пройдены.
