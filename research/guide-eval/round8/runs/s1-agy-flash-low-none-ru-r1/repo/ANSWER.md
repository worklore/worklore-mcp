# Исправление генератора тренировок (gen.py)

## Что изменено
В файле `gen.py` в функции `hr_target(step)` ключ нижней границы целевого диапазона пульса изменен с `"value"` на `"start"`:

```python
# Было:
return {"units": "%lthr", "value": lo, "end": hi}

# Стало:
return {"units": "%lthr", "start": lo, "end": hi}
```

## Причина изменения
В API Intervals.icu структура объекта целевого пульса в шаге тренировки (`workout_doc.steps[].hr`) имеет разную семантику в зависимости от названия ключа нижней границы:

1. **Пара `{ "value": lo, "end": hi }`**:
   Интерпретируется Intervals.icu как привязка шага к стандартным зонам пульса (Lap-HR / zone-mapped target). При экспорте тренировки в Garmin Connect и генерации FIT-файла Garmin сопоставляет такой шаг с собственными локальными зонами пульса устройства, обрезая границы коридора под границы системных зон часов (вместо запланированных 151–160 bpm на часах отображались границы зон часов 151–162 bpm).
2. **Пара `{ "start": lo, "end": hi }`**:
   Интерпретируется Intervals.icu как явный диапазон мгновенного пульса (Instant-HR corridor). При таком формате в FIT-файл для Garmin экспортируются точные целевые границы пульса (`custom_target_value_low` / `custom_target_value_high`), рассчитанные на основе LTHR атлета из профиля Intervals.icu (172 уд/мин), независимо от локальных зон и автоопределения на часах.
