# Исправление кеширования

В `bot.py` функция `build_system` теперь отправляет два текстовых блока с `cache_control: ephemeral`: неизменные `INSTRUCTIONS` и отдельный контекст спортсмена (дата, профиль, зоны, цель, факты, язык). После `save_fact` меняется только второй блок; первый остаётся тем же кешируемым префиксом для запросов с одинаковым набором инструментов.

Из заметки пригодились разделение статической и изменчивой частей двумя маркерами и проверка по `cache_read_input_tokens` / `cache_creation_input_tokens`. Фильтрация инструментов уже была в проекте, поэтому её не менял. Отбор фактов под отдельное сообщение здесь не нужен: текущий код передаёт все факты и сохраняет стабильность контекста между записями. Набор инструментов может меняться по ключевым словам, поэтому при его смене кешированный префикс может пересоздаваться независимо от памяти.

Локальная проверка подтвердила, что после добавления факта первый блок побайтно прежний, второй меняется и оба имеют маркер кеша. Реальные счётчики Anthropic после изменения не проверялись: внешние вызовы запрещены условием задачи. При доступной локальной проверке ожидаемый признак исправления после `save_fact` — чтение статического блока из кеша и создание кеша только для изменившегося хвоста при том же наборе инструментов и в пределах TTL.
