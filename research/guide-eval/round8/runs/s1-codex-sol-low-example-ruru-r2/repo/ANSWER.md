# Исправление пульсовых коридоров

В `gen.py` нижняя граница цели по пульсу теперь записывается в `hr.start`, а не в `hr.value`. Верхняя граница остаётся в `hr.end`, единица измерения — `%lthr`. Функция `hr_target` используется и для обычных шагов, и для шагов внутри повторов, поэтому исправление охватывает всю тренировку.

В сохранённом событии 184233 использовалась пара `value`/`end`; по `readback/watch-notes.md` часы показывали вместо запланированных коридоров границы собственных зон. Из заметки коллеги пригодилось различие между `start`/`end` (Instant HR) и `value`/`end` (цель по зонам), а также совет оставить проценты LTHR для пересчёта Intervals при экспорте. Варианты с `bpm` и `start_bpm`/`end_bpm` не использованы: их неудачный результат уже зафиксирован в readback.

Советы о текстовом поле `description` не применял: readback уже содержит непустой `workout_doc.steps`, а задача касается коридоров на часах. Проверка локального вывода генератора подтверждает `start`/`end` для всех четырёх видов шагов, включая повтор. Экспорт FIT и отображение на часах локально проверить нельзя; отправок во внешние сервисы не было.
