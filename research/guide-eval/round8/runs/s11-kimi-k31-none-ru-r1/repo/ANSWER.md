# Причина

При первой публикации библиотека пуста, поэтому поле `similar` сохраняется как пустой список. При повторной публикации функция `similarity()` вычисляет оценку сходства и возвращает `float`. Это значение попадает в `similar[].score` и затем в `table.put_item()`.

Сериализатор DynamoDB не поддерживает `float` и требует `Decimal`, поэтому выбрасывает `TypeError: Float types are not supported. Use Decimal types instead.` (`logs/error.log`). Общий обработчик исключений в `handler()` превращает эту ошибку в ответ 500.

# Исправление

В `src/app.py` оценка сходства преобразуется в `Decimal(str(...))` при формировании списка связанных историй, до передачи элемента в DynamoDB. Преобразование через строку исключает двоичные артефакты представления `float`; расчёт и округление оценки не изменились.

В `tests/test_publish.py` добавлен регрессионный тест: он выполняет две публикации через `handler()`, проверяет, что обе возвращают 201, и что сохранённая оценка сходства имеет тип `Decimal`.

# Проверка

`PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover tests -v` — 2 теста пройдены. Отдельный сценарий двух последовательных вызовов `handler()` также вернул 201 на обе публикации.
