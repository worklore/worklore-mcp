# Реализация аналитики

- На экране регистрации через `Analytics.capture` добавлены события `registration_email_started` и `registration_phone_started` при первом изменении соответствующего поля за время посещения экрана. Значения полей не передаются.
- `loan_amount_changed` отправляется после завершения взаимодействия со слайдером с целочисленным `amount`. `terms_accepted` отправляется при установке флажка. `registration_continue_tapped` отправляется при нажатии доступной кнопки с текущими `amount` и `terms`.
- На экране предложений `offers_scrolled` отправляется по завершении прокрутки с `offset` типа `double`, когда список прокручен от начальной позиции.

Из заметки коллеги пригодились ограничения частоты: первое изменение текстового поля, `onChangeEnd` для слайдера и `ScrollEndNotification` для списка. Рекомендация о событиях фокуса не потребовалась: таких событий нет в `docs/EVENTS.md`. Имена событий и свойства взяты из спецификации.

Проверка: `flutter analyze` завершился без замечаний; `git diff --check` не выявил ошибок форматирования. Отправка событий в PostHog вручную не проверялась.
