# Аналитика: события воронки регистрации

Реализованы все шесть событий из `docs/EVENTS.md`. Отправка идёт только через
`Analytics.capture`, без прямых вызовов PostHog. Имена событий и свойства
совпадают с описанием в `docs/EVENTS.md`.

## Что изменено

### `lib/screens/registration_screen.dart`

- `registration_email_started` — при первом символе в поле email. Флаг
  `_emailStarted` не даёт отправить событие повторно при каждом нажатии.
- `registration_phone_started` — то же для поля телефона (`_phoneStarted`).
- `loan_amount_changed` со свойством `amount` (int) — при отпускании слайдера
  (`onChangeEnd`), а не на каждом шаге перетаскивания.
- `terms_accepted` — только когда чекбокс отмечен (снятие галочки не
  отправляет событие).
- `registration_continue_tapped` со свойствами `amount` (int) и `terms` (bool) —
  при нажатии Continue, перед переходом на `/offers`. Кнопка активна только при
  выполнении условий, поэтому `terms` здесь всегда `true`, но значение
  передаётся из состояния.

### `lib/screens/offer_screen.dart`

- `offers_scrolled` со свойством `offset` (double, `metrics.pixels`) —
  отправляется по `ScrollEndNotification`, то есть один раз по окончании
  прокрутки, а не на каждом кадре.

## Решения, которые стоит проверить

1. **`loan_amount_changed` на `onChangeEnd`.** В описании сказано «moved the
   slider» и «the chosen amount». Поэтому выбран итоговое значение, а не поток
   значений во время перетаскивания. Это также экономит квоту бесплатного тарифа
   PostHog. Если нужны все промежуточные значения, замените `onChangeEnd` на
   `onChanged`.
2. **`offers_scrolled` на окончание прокрутки.** Одно событие на жест прокрутки.
   Программные прокрутки, если появятся, тоже будут учитываться.
3. **Started-события один раз за визит на экран.** Если пользователь очистил
   поле и начал вводить снова, событие повторно не уйдёт.

## Что не делалось

- PII не отправляется: ни email, ни телефон не передаются в свойствах.
- Просмотры экранов не добавлялись, их отправляет `PosthogObserver`.
- `README.md` не менялся. В нём всё ещё написано, что экраны не отправляют
  события. Эту строку стоит обновить отдельно.
- Ключ PostHog в `lib/analytics.dart` остался заглушкой `phc_REPLACE_ME_IN_CI`.
  Его нужно подставить в CI.

## Проверка

- `dart format --set-exit-if-changed lib` — изменений форматирования нет.
- `flutter analyze` — ошибок и предупреждений нет.
- Запуск приложения и проверка событий в PostHog не выполнялись: в этой
  среде нет доступа к реальному проекту PostHog, и отправка во внешний сервис
  запрещена правилами работы.
- Побочные изменения инструментов (`analysis_options.yaml`, `pubspec.lock`,
  `.dart_tool/`) откатаны, в рабочем дереве остались только два файла экранов
  и этот `ANSWER.md`.
