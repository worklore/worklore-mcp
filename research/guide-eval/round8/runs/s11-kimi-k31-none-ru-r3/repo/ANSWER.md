# Причина

Первая публикация успешна, потому что в пустой библиотеке поле `similar` сохраняется как пустой список. При второй публикации в `similar` появляется хотя бы один элемент с числовым полем `score`.

Функция `similarity()` возвращала `float`, и этот `float` попадал во вложенный элемент `Item` без преобразования. Сериализатор `boto3` для DynamoDB не принимает `float` и выбрасывает `TypeError: Float types are not supported. Use Decimal types instead.` Исключение перехватывалось общим обработчиком в `handler()`, поэтому клиент получал HTTP 500. Это соответствует трассировке в `logs/error.log`.

# Исправление

В `src/app.py` оценка похожести теперь преобразуется в `Decimal` через `str` при формировании элементов `similar`, до вызова `table.put_item()`. Расчёт и округление оценки не изменились, а в DynamoDB больше не передаётся неподдерживаемый тип `float`.

В `tests/test_publish.py` добавлен регрессионный тест двух последовательных запросов через `handler()`. Он проверяет, что оба ответа имеют статус 201, обе записи сохранены, а `score` второй записи имеет тип `Decimal`. Используемая имитация таблицы проверяет вложенные значения так же, как сериализатор `boto3`, поэтому возврат `float` снова приведёт к падению теста.

Проверка: `python3 -m unittest discover tests` — 2 теста, все успешно.
