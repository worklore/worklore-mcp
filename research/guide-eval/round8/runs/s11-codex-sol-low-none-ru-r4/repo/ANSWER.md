# Причина и исправление

`similarity()` возвращала оценку типа `float`. При первой публикации список `similar` пуст, поэтому запись сохранялась. При второй публикации в `similar[].score` появлялся `float`; сериализатор boto3 для DynamoDB отклоняет его с ошибкой `Float types are not supported`, а обработчик возвращает 500.

Теперь `similarity()` возвращает `Decimal` после округления до четырёх знаков. Значение, которое попадает в `similar[].score`, совместимо с DynamoDB при любой публикации с похожими историями. Добавлен тест, который публикует две истории через обработчик, проверяет оба ответа 201 и тип сохранённой оценки.
