# Реализация аналитики

- На экране регистрации добавлены `registration_email_started` и `registration_phone_started`: каждое событие отправляется один раз при первом непустом вводе в соответствующее поле за время жизни экрана. Адрес почты и номер телефона в свойства не попадают.
- `loan_amount_changed` отправляется после завершения взаимодействия с ползунком с целочисленным `amount`. `terms_accepted` отправляется при каждом переходе флажка из выключенного состояния во включённое. `registration_continue_tapped` отправляется при нажатии доступной кнопки с текущими `amount` (int) и `terms` (bool).
- На экране предложений `offers_scrolled` отправляется по окончании вертикальной прокрутки списка с `offset` (double).
- Все события идут через существующий `Analytics.capture`. События просмотра экранов не добавлялись.

Из заметки коллеги пригодились флаги для событий первого ввода, `onChangeEnd` для ползунка и `ScrollEndNotification` для списка: они не создают событие на каждое нажатие клавиши, шаг ползунка или обновление прокрутки. Отладка через PostHog и проверка в его интерфейсе не применялись: аналитические события во внешние сервисы не отправлялись.

Проверка: `flutter analyze` — ошибок нет. Работа приложения с реальным PostHog не проверялась.
