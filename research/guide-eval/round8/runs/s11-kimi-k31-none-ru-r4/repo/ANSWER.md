# Причина

`similarity()` возвращает оценку похожести типа `float`. При первой публикации библиотека пуста, поэтому в сохраняемом элементе `similar` — пустой список и ошибки нет. При второй публикации `related()` добавляет в `similar` словарь с полем `score` типа `float`.

Сериализатор boto3 для DynamoDB не поддерживает `float` и требует `Decimal`. Поэтому `table.put_item()` выбрасывает `TypeError: Float types are not supported. Use Decimal types instead.` (см. `logs/error.log`), а общий обработчик исключений в `handler()` возвращает HTTP 500.

# Исправление

В `src/app.py` оценка теперь преобразуется в `Decimal(str(similarity(...)))` перед добавлением в `similar`. Это сохраняет уже округлённое десятичное представление оценки и делает элемент совместимым с сериализатором DynamoDB. Сортировка оценок продолжает работать, поскольку `Decimal` поддерживает числовое сравнение.

В `tests/test_publish.py` добавлен регрессионный тест: он выполняет две публикации подряд, проверяет сохранение обеих историй и тип `Decimal` у оценки похожести. До исправления этот тест воспроизводил исходный `TypeError`.

# Проверка

- `python3 -m unittest discover tests` — 2 теста успешно.
- Два последовательных вызова `handler()` с локальным `FakeTable` — оба вернули `201`, в таблице оказалось 2 элемента.
