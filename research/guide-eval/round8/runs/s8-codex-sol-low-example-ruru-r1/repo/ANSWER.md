# Исправление кеширования

В `bot.py` системный промпт разделён на два текстовых блока с `cache_control: ephemeral`: неизменные инструкции и изменяемый контекст атлета (дата, профиль, зоны, цель, факты, язык). После `save_fact` меняется только второй блок; первый остаётся побайтно тем же при неизменном наборе инструментов.

Из заметки пригодились идея двух точек кеширования и требование проверять стабильность префикса. Отбор фактов под сообщение не добавлял: он менял бы контекст при каждом запросе. Фильтрацию инструментов оставил как есть, согласно `NOTES.md`; при смене их набора кешированный префикс тоже может измениться. Точные `cache_read_input_tokens` и `cache_creation_input_tokens` на реальном API здесь не проверял: внешние вызовы запрещены.

Локально проверил, что оба блока имеют маркеры, после добавления факта первый блок и список инструментов не меняются, а второй содержит новый факт. Также прошли `py_compile` и `git diff --check`.
