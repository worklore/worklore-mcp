# Причина

`similarity()` возвращал оценку связности как `float`. При первой публикации список `similar` был пуст, поэтому запись в DynamoDB проходила. При второй публикации в `similar` появлялся элемент с полем `score` типа `float`, которое сериализатор boto3 для DynamoDB не поддерживает. В результате `table.put_item()` выбрасывал `TypeError: Float types are not supported. Use Decimal types instead.`, а обработчик возвращал 500.

# Исправление

В `src/app.py` результат `similarity()` теперь преобразуется в `Decimal` через строковое представление уже округлённого значения. Это сохраняет прежнюю точность в четыре знака и создаёт числовой тип, поддерживаемый DynamoDB.

В `tests/test_publish.py` добавлен регрессионный тест: две истории последовательно публикуются через `handler()`, обе публикации должны вернуть 201, а `score` второй истории проверяется как `Decimal`. Проверка `python3 -m unittest discover tests` проходит: 2 теста.
