# Реализация событий аналитики

Добавлены все шесть событий из `docs/EVENTS.md` через существующую обёртку `Analytics.capture`:

- На экране регистрации `registration_email_started` и `registration_phone_started` отправляются при первом вводе в соответствующее поле, один раз за посещение экрана. Email и номер телефона не передаются.
- `loan_amount_changed` отправляется после завершения изменения слайдера, если сумма изменилась. Свойство `amount` — целое число.
- `terms_accepted` отправляется при установке галочки, `registration_continue_tapped` — при нажатии доступной кнопки Continue со свойствами `amount` и `terms`.
- На экране предложений `offers_scrolled` отправляется после завершения фактической прокрутки. Свойство `offset` — число типа `double`, смещение списка в пикселях.

Из заметки коллеги пригодились ограничение событий ввода одним срабатыванием за посещение экрана, перенос события слайдера на `onChangeEnd`, отправка события прокрутки на `ScrollEndNotification` и сохранение точных имён и свойств событий. Приём с потерей фокуса не понадобился: спецификация не требует итоговых значений полей.

Проверка: `flutter analyze --no-pub` — ошибок нет. Зависимости для проверки были разрешены локально через `flutter pub get --offline`; события во внешний сервис не отправлялись.
