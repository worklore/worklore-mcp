# Аналитика: события воронки регистрации

Реализованы все шесть событий из `docs/EVENTS.md`. Отправка идёт только через `Analytics.capture`, ключ и хост не трогались.

## Экран регистрации (`lib/screens/registration_screen.dart`)

| Событие | Где срабатывает | Свойства |
|---|---|---|
| `registration_email_started` | Первый непустой ввод в поле email (один раз за визит на экран) | — |
| `registration_phone_started` | Первый непустой ввод в поле телефона (один раз за визит на экран) | — |
| `loan_amount_changed` | `onChanged` слайдера | `amount` (int, `v.round()`) |
| `terms_accepted` | Галочка поставлена (снятие галочки не отправляет событие) | — |
| `registration_continue_tapped` | Нажатие Continue, только когда кнопка активна | `amount` (int), `terms` (bool) |

Email и телефон в свойства не попадают (PII).

## Экран предложений (`lib/screens/offer_screen.dart`)

| Событие | Где срабатывает | Свойства |
|---|---|---|
| `offers_scrolled` | `ScrollEndNotification` у списка | `offset` (double, `metrics.pixels`) |

Событие отправляется по окончании прокрутки, а не на каждый кадр.

## Решения, которые стоит проверить

- **`loan_amount_changed` на каждом шаге слайдера.** `onChanged` вызывается непрерывно во время перетаскивания, поэтому при одном движении уйдёт много событий. Если продукт считает одним действием всё перетаскивание, нужно заменить на `onChangeEnd`. Сейчас сделано по букве документа («moved»).
- **`offers_scrolled` по `ScrollEndNotification`.** Это одно событие на жест. Значение `offset` — позиция в пикселях в момент остановки.
- **Started-события** сбрасываются при новом открытии экрана регистрации, потому что флаги живут в состоянии виджета.
