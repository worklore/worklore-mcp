# Отчёт: события аналитики регистрационной воронки

Реализованы все 6 событий из `docs/EVENTS.md` через существующую обёртку
`Analytics.capture` (`lib/analytics.dart`). Отправка — fire-and-forget
(вызовы обёрнуты в `unawaited`, чтобы не блокировать UI).

## Экран регистрации — `lib/screens/registration_screen.dart`

| Событие | Где срабатывает | Свойства |
|---|---|---|
| `registration_email_started` | Первое изменение текста в поле Email (один раз за визит экрана) | — |
| `registration_phone_started` | Первое изменение текста в поле Phone (один раз за визит экрана) | — |
| `loan_amount_changed` | Отпускание ползунка суммы (`Slider.onChangeEnd`) | `amount` (int) |
| `terms_accepted` | Постановка галочки terms (только при значении `true`, при снятии не шлём) | — |
| `registration_continue_tapped` | Тап по кнопке Continue, перед навигацией | `amount` (int), `terms` (bool) |

## Экран предложений — `lib/screens/offer_screen.dart`

| Событие | Где срабатывает | Свойства |
|---|---|---|
| `offers_scrolled` | Прокрутка списка (`NotificationListener<ScrollUpdateNotification>`) | `offset` (double, `metrics.pixels`) |

Экран превращён в StatefulWidget для хранения состояния троттлинга.

## Принятые решения

- **PII не отправляется**: email и телефон нигде не попадают в свойства —
  отправляется только факт начала ввода.
- **`_started`-события — один раз за визит экрана**, а не на каждый символ
  (флаги `_emailStarted`/`_phoneStarted`).
- **`loan_amount_changed` шлётся на отпускании ползунка**, а не на каждый тик
  перетаскивания: `onChanged` срабатывает десятки раз за одно движение,
  а в доке указано «the chosen amount». Итоговое значение совпадает с тем,
  что видит пользователь.
- **`offers_scrolled` троттлится до 1 события в секунду** — иначе каждый пиксель
  прокрутки порождал бы событие. В `offset` уходит текущая позиция прокрутки.
- Имена событий — точно как в таблице, snake_case, без изменений.
- События просмотров экранов не добавлялись — по доке они трекаются
  автоматически (`PosthogObserver` в `lib/main.dart` уже стоит).

## Проверка

Полный прогон анализатора/тестов не выполнен: в этой среде запуск
`flutter`/`dart` запрещён (Operation not permitted). Изменения вручную
проверены на соответствие `flutter_lints` (нет необработанных futures,
используются `unawaited`, нет неиспользуемых импортов).
