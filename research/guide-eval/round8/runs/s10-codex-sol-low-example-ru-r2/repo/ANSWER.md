# Реализация событий аналитики

- На экране регистрации добавлены `registration_email_started` и `registration_phone_started`: каждое отправляется один раз при первом изменении соответствующего поля за посещение экрана. Значения email и телефона не передаются.
- `loan_amount_changed` отправляется по завершении взаимодействия со слайдером с целочисленным `amount`; `terms_accepted` — при установке флажка; `registration_continue_tapped` — при нажатии Continue с `amount` и `terms`.
- На экране предложений `offers_scrolled` отправляется после завершения прокрутки с `offset` типа double. Все события проходят через существующий `Analytics.capture`.

Из заметки коллеги пригодились ограничение событий ввода одним срабатыванием за посещение экрана, `onChangeEnd` для слайдера и `ScrollEndNotification` для списка. Советы о PostHog debug и проверке в Activity не применялись: внешние сервисы не использовались.

Проверка: `flutter pub get --offline`, затем `flutter analyze --no-pub` — ошибок нет. Зависимости восстанавливались только из локального кэша.
