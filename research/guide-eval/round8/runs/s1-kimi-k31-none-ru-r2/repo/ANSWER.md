# Исправление диапазонов пульса

В `hr_target()` в `gen.py` добавлено поле `custom: true` для каждой HR-цели. Значения `units: "%lthr"`, `value` и `end` не изменены, поэтому границы по-прежнему задаются в процентах LTHR из плана.

Без признака произвольной цели Garmin заменял переданный коридор собственной зоной пульса. Поле `custom: true` сохраняет именно заданный диапазон вместо привязки к зонам часов.

Локально проверен вывод `python3 gen.py plans/tempo-run.json`: все четыре шага содержат исходные диапазоны 68–75, 88–93, 75–82 и 65–72 % LTHR с `custom: true`; структура повторов сохранена. Наружу данные не отправлялись.
