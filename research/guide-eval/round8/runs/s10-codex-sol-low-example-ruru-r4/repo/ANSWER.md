# Реализация аналитики

Добавлены все шесть событий из `docs/EVENTS.md` через существующую обёртку `Analytics.capture`:

- Первое редактирование email и телефона отправляет `registration_email_started` и `registration_phone_started` по одному разу за время жизни экрана. Значения полей не передаются.
- После окончания движения слайдера отправляется `loan_amount_changed` с целочисленным `amount`.
- При установке флажка отправляется `terms_accepted`; при нажатии активной кнопки Continue — `registration_continue_tapped` с `amount` и `terms`.
- После завершения прокрутки списка отправляется `offers_scrolled` с `offset` типа `double`.

Из заметки коллеги пригодились ограничение событий ввода флагами и перенос событий слайдера и прокрутки на завершение жеста. Советы про FocusNode и PostHog debug не понадобились: итоговые значения текстовых полей спецификация не запрашивает, а отправлять события во внешний сервис для проверки нельзя.

Проверка: `flutter analyze` завершился без замечаний. Реальную отправку событий не проверял, чтобы не обращаться к внешнему сервису.
