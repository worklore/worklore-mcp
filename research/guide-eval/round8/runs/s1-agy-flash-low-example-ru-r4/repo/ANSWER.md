# Отчёт об исправлении генератора тренировок

## Что изменено в коде
В файле [`gen.py`](file:///tmp/h-cgIiPn/gen.py) в функции `hr_target(step)` ключ нижней границы диапазона пульса изменён с `"value"` на `"start"`:

```python
# До:
return {"units": "%lthr", "value": lo, "end": hi}

# После:
return {"units": "%lthr", "start": lo, "end": hi}
```

## Почему это исправляет проблему
При экспорте тренировки из Intervals.icu в формат FIT для часов Garmin:
- Структура `{"units": "%lthr", "value": lo, "end": hi}` интерпретируется как Lap-HR / zone-mapped цель. В этом режиме часы Garmin принудительно привязывают (clamp) целевой диапазон к границам собственных локальных пульсовых зон часов (в данном случае это были зоны 118–137, 151–162 и т.д.), игнорируя точные границы шагов.
- Структура `{"units": "%lthr", "start": lo, "end": hi}` соответствует режиму «Instant HR» коридора. Intervals.icu самостоятельно пересчитывает проценты `%lthr` в абсолютные значения bpm по сохранённому порогу атлета (LTHR 172) и передаёт точный коридор bpm в FIT-файл, отображая именно запланированные значения пульса на часах без искажения локальными зонами часов.

## Какие части заметки коллеги пригодились
- **Пригодилось:**
  - Описание ключевого различия в схеме: `{"start", "end"}` против `{"value", "end"}`. Замена ключа `"value"` на `"start"` переключает режим экспорта с zone-mapped на Instant-HR коридор.
  - Подтверждение единиц измерения (`"units": "%lthr"`): передавать нужно именно процент от LTHR, а не абсолютные bpm (так как Intervals сам конвертирует проценты в bpm при FIT-экспорте).
- **Не пригодилось (пропущено):**
  - Описание неудачных попыток: `{units: "bpm", value, end}` и `{start_bpm, end_bpm}` (они уже были опробованы ранее и зафиксированы в `watch-notes.md`).
  - Текстовое поле `description` и особенности парсера Intervals web UI (грамматика `m`/`s`, `mtr`/`km`, повторы `Nx` и т.д.), так как генератор `gen.py` генерирует напрямую структуру `workout_doc`, принимаемую API, и задача заключалась исключительно в исправлении коридоров пульса.
  - Пошаговые инструкции по настройке API-ключа, ручному созданию событий через `POST /api/v1/athlete/{id}/events` и верификации на физических часах (по правилам работа производилась строго локально без внешних сетевых запросов).
