# Исправление диапазонов пульса

Генератор теперь переводит `hr_pct` в удары в минуту по `lthr_bpm` из плана (для этого плана — 172) и формирует цель с `units: "bpm"`. Цель в `%lthr` убрана: согласно `readback/watch-notes.md`, часы показывали для неё границы своих зон вместо запланированного коридора.

При прежней попытке передать абсолютные значения с `units: "bpm"` часы показали завышенные значения 214–249 bpm. Поэтому в `gen.py` сосредоточена поправка экспорта −100 bpm к обоим концам диапазона. Для текущего плана в JSON уходят 17–29, 51–60, 29–41 и 12–24; с этой поправкой ожидаемые значения на часах — 117–129, 151–160, 129–141 и 112–124 bpm. Генератор проверяет LTHR и порядок границ диапазона.

Локальная проверка подтвердила сформированные диапазоны, порядок шагов и три повтора блока. Экспорт в Intervals/Garmin и отображение на часах здесь не проверялись: правило задачи запрещает обращения к внешним сервисам. Поправка −100 основана на записи о прежней пробе; без её JSON и нового readback нельзя подтвердить, что она исправляет все шаги на часах.
