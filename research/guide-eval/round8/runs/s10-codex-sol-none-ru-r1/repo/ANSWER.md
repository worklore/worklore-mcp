# Реализованные события аналитики

- На экране регистрации добавлены `registration_email_started` и `registration_phone_started` при первом вводе в соответствующее поле за открытие экрана. Значения полей в аналитику не передаются.
- При изменении суммы отправляется `loan_amount_changed` с целым `amount`; при установке флажка — `terms_accepted`.
- Нажатие доступной кнопки Continue отправляет `registration_continue_tapped` с `amount` и `terms` перед переходом к предложениям.
- После фактической прокрутки списка предложений отправляется `offers_scrolled` с итоговым `offset` типа `double`.

Все события проходят через `Analytics.capture`. Проверки форматирования и `git diff --check` пройдены. `flutter analyze --no-pub` не смог разрешить зависимости Flutter и PostHog: в рабочей директории нет скачанных пакетов; загрузка из внешнего сервиса не выполнялась.
