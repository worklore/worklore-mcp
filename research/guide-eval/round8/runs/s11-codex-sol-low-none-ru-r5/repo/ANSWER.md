# Причина сбоя

При первой публикации таблица пуста, поэтому поле `similar` сохраняется как пустой список. При следующей публикации `related()` добавляет в него оценку сходства `score`, которую `similarity()` вычисляет как `float`. Сериализатор boto3 для DynamoDB запрещает значения `float`; вызов `put_item()` выбрасывает `TypeError`, а обработчик отвечает 500. Это совпадает с трассировкой в `logs/error.log`.

# Исправление

Перед записью каждой оценки в `similar` она преобразуется в `Decimal` через строковое представление. Таким образом, все оценки, включая нулевые, имеют поддерживаемый DynamoDB тип. Добавлен тест, который выполняет две публикации через обработчик и проверяет сохранённую оценку.

Проверка: `python3 -m unittest discover tests -v` — 2 теста прошли.
