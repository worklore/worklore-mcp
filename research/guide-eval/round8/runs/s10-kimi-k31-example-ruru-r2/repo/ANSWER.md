# Что сделано

Все события из `docs/EVENTS.md` подключены через существующий `Analytics.capture`.

## Экран регистрации

В `lib/screens/registration_screen.dart` добавлены:
- `registration_email_started` — при первом редактировании email за посещение экрана;
- `registration_phone_started` — при первом редактировании телефона за посещение экрана;
- `loan_amount_changed` — после завершения перетаскивания слайдера, со свойством `amount` типа `int`;
- `terms_accepted` — только при установке флага согласия, но не при его снятии;
- `registration_continue_tapped` — при нажатии Continue перед переходом к предложениям, со свойствами `amount` (`int`) и `terms` (`bool`).

Email и номер телефона в свойства событий не передаются.

## Экран предложений

В `lib/screens/offer_screen.dart` добавлено событие `offers_scrolled`. Оно отправляется по `ScrollEndNotification` после завершения прокрутки и содержит текущее смещение списка в свойстве `offset` (`double`).

## Что пригодилось из заметки коллеги

- Флаги «один раз за посещение экрана» для событий начала ввода, чтобы не отправлять событие на каждое нажатие клавиши.
- Перенос события слайдера из `onChanged` в `onChangeEnd`.
- Использование `ScrollEndNotification` вместо событий каждого обновления прокрутки.
- Сохранение точных имён событий и свойств из спецификации.

Рекомендации про отправку итогового значения при потере фокуса не применялись: спецификация таких свойств для email и телефона не требует, а сами значения являются персональными данными.
