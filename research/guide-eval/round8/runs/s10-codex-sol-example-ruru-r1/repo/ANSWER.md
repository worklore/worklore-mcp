# Реализация событий аналитики

Добавлены все шесть событий из `docs/EVENTS.md` через существующий `Analytics.capture`.

- На экране регистрации `registration_email_started` и `registration_phone_started` отправляются при первом вводе в соответствующее поле за открытие экрана. Email и телефон в свойства не передаются.
- `loan_amount_changed` отправляется после завершения изменения слайдера с выбранной суммой `amount` типа `int`.
- `terms_accepted` отправляется при установке флажка. `registration_continue_tapped` отправляется при нажатии доступной кнопки Continue с `amount` (`int`) и `terms` (`bool`).
- На экране предложений `offers_scrolled` отправляется после завершения прокрутки, если позиция изменилась. `offset` — смещение списка в пикселях типа `double` в пределах доступного диапазона.

Из заметки коллеги пригодились: защита событий ввода от отправки на каждый символ, `onChangeEnd` для слайдера и `ScrollEndNotification` для списка. Сценарий с событием при потере фокуса не нужен: спецификация не запрашивает итоговые значения полей. Отладочную отправку в PostHog не запускал, так как по условию нельзя обращаться к внешним сервисам.

Проверка: `dart format` и `flutter analyze --no-pub` прошли без замечаний; зависимости разрешены из локального кэша командой `flutter pub get --offline`.
