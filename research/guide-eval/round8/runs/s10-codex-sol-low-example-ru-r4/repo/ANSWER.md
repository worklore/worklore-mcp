# Реализация аналитики

- На экране регистрации через `Analytics.capture` добавлены события `registration_email_started` и `registration_phone_started` при первом изменении соответствующего поля за открытие экрана. Значения полей не передаются.
- `loan_amount_changed` отправляется по завершении движения слайдера с целым `amount`; `terms_accepted` — при установке флажка; `registration_continue_tapped` — при нажатии доступной кнопки Continue с `amount` и `terms`.
- На экране предложений `offers_scrolled` отправляется по завершении прокрутки списка с `offset` типа `double`.

Из заметки коллеги пригодились ограничение событий ввода одним вызовом за открытие экрана, перенос события слайдера в `onChangeEnd` и использование `ScrollEndNotification` для списка. Имена событий и свойства взяты из `docs/EVENTS.md`. Советы о PostHog debug и проверке квоты не применялись: внешние сервисы не использовались.

Проверка: `flutter analyze` — ошибок нет.
