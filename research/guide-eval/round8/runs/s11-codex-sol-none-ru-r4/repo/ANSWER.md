# Причина и исправление

Первая публикация проходит, потому что в пустой таблице нет похожих историй: `similar` равен пустому списку. При следующей публикации `related()` добавляет в `similar` оценку `score`, которую `similarity()` раньше вычисляла как `float`. В `logs/error.log` видно, что `boto3` отклоняет такой элемент при `put_item`: `Float types are not supported. Use Decimal types instead.` Из-за этого обработчик возвращал 500.

Расчёт сходства теперь выполняется с `Decimal` и округляется до четырёх знаков, поэтому в сохраняемом `similar[].score` нет `float`. Добавлен регрессионный тест с тремя последовательными публикациями через обработчик: он проверяет ответы 201, число сохранённых историй и тип всех оценок. Проверка: `python3 -m unittest discover tests` — 2 теста прошли.
