# Реализация событий аналитики

На экране регистрации добавлены `registration_email_started`, `registration_phone_started`, `loan_amount_changed`, `terms_accepted` и `registration_continue_tapped`. На экране предложений добавлено `offers_scrolled`. Все события отправляются через существующую `Analytics.capture`, с именами и свойствами из `docs/EVENTS.md`. Email и телефон не передаются в свойствах; дополнительные события просмотра экранов не добавлялись.

Из заметки коллеги пригодились ограничения частоты отправки: события начала ввода отправляются один раз за время жизни экрана, изменение суммы — после завершения движения слайдера, прокрутка — по `ScrollEndNotification`. Имена и свойства событий сохранены. Советы о потере фокуса и итоговом значении поля не понадобились, поскольку спецификация таких значений не требует. Настройка отладочного PostHog и проверка в его Activity не применялись: внешние сервисы не использовались.

Проверка: `dart format` выполнен; `flutter analyze --no-pub` завершился без замечаний после локального `flutter pub get --offline`. Созданные этой проверкой служебные файлы удалены.
