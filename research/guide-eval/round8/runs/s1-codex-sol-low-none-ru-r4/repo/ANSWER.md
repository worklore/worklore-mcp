# Исправление диапазонов пульса

Генератор теперь переводит `hr_pct` в конкретные границы пульса по `lthr_bpm` из плана и передаёт их как `bpm`. Для наблюдавшегося пути Intervals → Garmin из обеих границ вычитается 100: в предыдущей попытке с абсолютными значениями часы показывали примерно на 100 уд/мин больше. Процентные цели попадали на часы как целые зоны, поэтому они больше не используются в выходном `workout_doc`.

Для LTHR 172 план даёт 117–129, 151–160, 129–141 и 112–124 уд/мин. В отправляемом JSON это соответственно 17–29, 51–60, 29–41 и 12–24: смещение компенсируется при экспорте. В план добавлен `lthr_bpm: 172`; его нужно обновлять при изменении порога спортсмена.

Локально проверены генерация JSON, синтаксис Python и `git diff --check`. Экспорт и показания часов повторно не проверялись, поскольку это потребовало бы обращения к внешним сервисам.
