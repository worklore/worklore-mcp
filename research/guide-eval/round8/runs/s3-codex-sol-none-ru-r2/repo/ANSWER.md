# Почему не приходили ночные сообщения

Задача **запускалась**. В `launchctl-print.txt` указаны 6 запусков, календарный триггер на 02:30 и последний код выхода 1. Ошибка не в регистрации `LaunchAgent` или расписании.

1. В `Library/Logs/nightly-review.err` после каждого запуска есть `Not logged in · Please run /login`. У `claude` не было действующей авторизации в окружении фоновой задачи, поэтому обзор не создавался. Запись этого сообщения шла в stderr, а не в пустой `nightly-review.out`.
2. Сразу после вызова `claude` скрипт присваивал `$?` переменной `status`. В zsh `status` — специальная переменная только для чтения. Ошибка `read-only variable: status` обрывала скрипт до ветки с уведомлением о сбое. Это повторяется после каждого сообщения `Not logged in` в stderr.

## Что исправлено в снимке

- В `bin/nightly-review.zsh` код выхода сохраняется в `claude_exit`; ветка ошибки теперь выполняется. Если нет `ANTHROPIC_API_KEY` или `CLAUDE_CODE_OAUTH_TOKEN`, скрипт пробует взять API-ключ из локальной связки ключей macOS по имени службы `anthropic-api-key`. Если ключ отсутствует и `claude` по-прежнему не авторизован, ошибка будет отправлена через `notify.sh`.
- В `bin/notify.sh` `curl` теперь завершается с ошибкой при HTTP 4xx/5xx, чтобы отказ Telegram был виден в stderr задачи.

Для полноценной работы на исходном Mac нужно **локально** предоставить `claude` действующую авторизацию для фонового запуска: сохранить API-ключ в Keychain как generic password со службой `anthropic-api-key` либо настроить действующую авторизацию CLI для того же пользователя. Ключ не следует записывать в plist или этот снимок. Доступ `notify.sh` к существующему ключу `tg-bot` также должен сохраняться у пользователя, запускающего агент. Эти учётные данные в снимке отсутствуют, поэтому реальную доставку здесь проверить нельзя.

Проверено локально: `plutil -lint` для plist, синтаксис обоих скриптов и два запуска с подставными командами без сетевых запросов. При подставной ошибке `claude` код выхода был 42 и сформировалось сообщение `FAILED`; при успехе сформировалось сообщение `done`.
