# Причина и исправление

Первая публикация проходит, потому что в пустой библиотеке поле `similar` равно пустому списку. При следующей публикации `similarity()` вычисляла оценки похожести как `float`; они попадали в `similar[].score`. При `put_item` сериализатор boto3 отклоняет `float` с ошибкой `TypeError: Float types are not supported. Use Decimal types instead.`, и обработчик возвращает 500.

В `src/app.py` вычисление оценок переведено на `Decimal`, включая веса и округление до четырёх знаков. Поэтому в сохраняемый объект больше не попадает `float` из оценки похожести. Добавлен тест последовательной публикации трёх историй: каждая возвращает 201, а сохранённые оценки имеют тип `Decimal`. Проверка: `python3 -m unittest discover tests` — 2 теста прошли.
