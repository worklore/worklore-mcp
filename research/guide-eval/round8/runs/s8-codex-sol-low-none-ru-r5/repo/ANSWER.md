# Исправление кеширования промпта

В `bot.py` разделил системный промпт на два текстовых блока с отдельными точками кеширования: постоянные инструкции и изменяемый контекст спортсмена. После `save_fact` меняется только второй блок, поэтому при одинаковом наборе инструментов API может повторно использовать кешированный префикс с инструкциями. Контекст с новым фактом по-прежнему передаётся в следующем запросе.

Проверил локально без обращения к API: после добавления факта первый блок и набор инструментов остались прежними, второй блок изменился; обе точки кеширования присутствуют. Фактические показатели `cache_read_input_tokens` требуют следующего реального вызова API. При изменении набора инструментов кеш префикса всё ещё может не совпасть, поскольку инструменты предшествуют системному промпту в порядке кеширования API.
