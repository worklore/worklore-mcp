# Что сделано

Реализованы все 6 событий аналитики из `docs/EVENTS.md` через существующую
обёртку `Analytics.capture` (ключ и хост PostHog по-прежнему живут только в
`lib/analytics.dart`).

## lib/screens/registration_screen.dart

- `registration_email_started` — при первом вводе символа в поле Email
  (один раз за визит экрана, флаг `_emailStarted`). Значение email не
  отправляется (PII).
- `registration_phone_started` — при первом вводе символа в поле Phone
  (один раз за визит, флаг `_phoneStarted`). Номер не отправляется (PII).
- `loan_amount_changed` — в `onChanged` слайдера, свойство `amount` (int,
  `value.round()`).
- `terms_accepted` — при установке галочки (переход в `true`).
- `registration_continue_tapped` — по нажатию Continue, свойства
  `amount` (int) и `terms` (bool); событие отправляется до навигации
  на `/offers`.

## lib/screens/offer_screen.dart

- Экран превращён из `StatelessWidget` в `StatefulWidget` с
  `ScrollController`.
- `offers_scrolled` — по изменению offset списка (листенер контроллера,
  без дублирования при неизменном offset), свойство `offset` (double).
  Контроллер освобождается в `dispose()`.

## Решения и допущения

- События `*_started` отправляются один раз за визит экрана при первом
  непустом вводе — соответствует смыслу «started» и не спамит на каждый
  символ. Остальные события отправляются на каждое срабатывание
  (спека `docs/EVENTS.md` не требует троттлинга).
- Имена событий и типы свойств (`amount` — int, `terms` — bool,
  `offset` — double) совпадают со спекой один в один.
- Email и телефон нигде не передаются как свойства — только факт начала
  ввода, как указано в заметках спеки.

## Проверка

- Полный `flutter analyze` / запуск приложения не выполнялись сознательно:
  зависимости не закешированы, `pub get` потребовал бы обращения к pub.dev,
  а запуск приложения инициализировал бы PostHog — по условиям задачи
  внешние сервисы недопустимы (бинарник `dart` для локальной проверки
  синтаксиса в этой среде также заблокирован).
- Изменённые файлы проверены ревью: сигнатуры `Analytics.capture`, типы
  колбэков Flutter-виджетов и соответствие спеке событий.
