# Реализация событий аналитики

- На экране регистрации через `Analytics.capture` добавлены `registration_email_started` и `registration_phone_started` при первом вводе символа, `loan_amount_changed` при изменении значения с целочисленным `amount`, `terms_accepted` при установке флажка и `registration_continue_tapped` при нажатии доступной кнопки с `amount` и `terms`.
- На экране предложений добавлен `offers_scrolled` после завершения прокрутки, если позиция списка изменилась. Свойство `offset` содержит текущее смещение списка типа `double`.
- Email и телефон не передаются в свойствах событий. Отслеживание просмотров экранов не менялось.

Проверка: `flutter analyze --no-pub` — без замечаний. Зависимости были разрешены локально командой `flutter pub get --offline`; внешние сервисы не вызывались.
