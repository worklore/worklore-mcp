# Исправление кеширования

В `bot.py` разделил системный промпт на два текстовых блока с отдельными `cache_control`: неизменные `INSTRUCTIONS` идут первыми, профиль и долговременная память спортсмена — вторыми. После `save_fact` меняется только второй блок; стабильный префикс может читаться из кеша, а обновлённый факт остаётся доступен уже в следующем раунде.

Проверил локально: `python3 -m py_compile bot.py`. Фактические счётчики кеша без вызова API не проверял. У API есть минимальный размер кешируемого префикса, поэтому экономия для короткого префикса зависит от его токенизации и набора инструментов в запросе.
