# Исправление кеширования

В `bot.py` разделил системный промпт на два текстовых блока с отдельными `cache_control`: неизменные инструкции идут первыми, затем профиль спортсмена и долговременные факты. После `save_fact` меняется только второй блок, поэтому прежний кеш статических инструкций остаётся пригодным, а новый факт доступен уже в следующем вызове модели.

Уточнил постоянные правила тренера, чтобы статический префикс достигал минимального размера для кеширования у используемой модели. Фильтрация инструментов по ключевым словам не менялась.

Проверил локально: `python3 -m py_compile bot.py` и проверка сборки запроса до и после `save_fact` прошли. Реальный API не вызывался; значения `cache_read_input_tokens` после исправления здесь не измерялись.
