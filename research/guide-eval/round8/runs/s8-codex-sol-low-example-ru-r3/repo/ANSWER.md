# Исправление кеширования

В `bot.py` функция `build_system` теперь передаёт два текстовых блока с `cache_control: ephemeral`: сначала неизменные `INSTRUCTIONS`, затем контекст спортсмена с датой, профилем и долговременными фактами. После `save_fact` меняется только второй блок, поэтому кешированный префикс с инструкциями может использоваться снова. Новый факт по-прежнему попадает в следующий запрос, в том числе в следующий раунд вызова инструментов.

Из заметки коллеги пригодились разделение стабильной и изменяемой частей двумя маркерами и проверка неизменности первой части после записи факта. Выбор инструментов по ключевым словам уже существовал; его не менял. Отбор отдельных фактов по сообщению не добавлял, чтобы состав контекста не менялся без записи в память.

Локальная проверка с `python3 -B` подтвердила, что оба блока имеют маркеры, первый блок остаётся идентичным после добавления факта, а второй меняется и содержит новый факт. Реальные показатели `cache_read_input_tokens` и `cache_creation_input_tokens` после изменения не измерялись: для этого потребовался бы вызов внешнего API. При изменении набора инструментов кешированный префикс также может перестроиться.
