# Исправление кеширования

В `bot.py` функция `build_system` теперь передаёт системный промпт двумя текстовыми блоками с отдельными `cache_control: ephemeral`. Первый содержит неизменные `INSTRUCTIONS`, второй — дату, профиль и долговременные факты спортсмена. После `save_fact` меняется только второй блок; стабильный префикс остаётся пригодным для чтения из кеша.

Из заметки коллеги пригодились разделение кешируемого промпта перед изменяемыми данными и проверка стабильности частей запроса, предшествующих системному контексту. Подбор инструментов по ключевым словам уже реализован; его не менял, поскольку `NOTES.md` фиксирует его пользу и просит сохранить. Отбор отдельных фактов для каждого сообщения не добавлял: он делал бы контекст изменчивым без необходимости.

Локально проверено без вызова API: оба блока имеют маркеры кеша, после добавления факта первый блок и список инструментов не меняются, а второй содержит новый факт. Также прошли `python3 -m py_compile bot.py` и `git diff --check`. Фактические значения `cache_read_input_tokens` и `cache_creation_input_tokens` после правки можно подтвердить только следующими реальными вызовами; внешние сервисы не вызывались.
