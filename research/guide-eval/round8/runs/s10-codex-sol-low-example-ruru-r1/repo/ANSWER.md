# Реализация аналитики

На экране регистрации через существующую `Analytics.capture` добавлены события из `docs/EVENTS.md`:

- `registration_email_started` и `registration_phone_started` — по одному разу при первом вводе непустого значения за посещение экрана. Email и телефон в свойства не передаются.
- `loan_amount_changed` — после завершения перемещения слайдера, с выбранной целочисленной суммой в `amount`.
- `terms_accepted` — при установке флажка, включая повторное принятие после снятия.
- `registration_continue_tapped` — при нажатии доступной кнопки Continue, со свойствами `amount` (int) и `terms` (bool).

На экране предложений добавлено `offers_scrolled` со свойством `offset` (double). Событие отправляется после завершения прокрутки, только если позиция списка действительно менялась. Автоматический учёт просмотров экранов не изменён.

Из заметки коллеги пригодились ограничение событий ввода флагом, `onChangeEnd` для слайдера и отправка события прокрутки по `ScrollEndNotification`. Отправка на каждое изменение текста, положения слайдера или прокрутки не нужна. Советы про фокус и итоговые значения полей не применялись: спецификация таких событий и свойств не требует.

Проверка: `flutter analyze` — без замечаний. Работа выполнена локально; события во внешний сервис не отправлялись.
