# Исправление генератора тренировок (gen.py)

### Что изменено
В функции [`hr_target`](file:///tmp/h-opsrsD/gen.py#L10-L13) файла [gen.py](file:///tmp/h-opsrsD/gen.py) ключ нижней границы целевого диапазона пульса изменен с `"value"` на `"start"`:

```python
# Было:
return {"units": "%lthr", "value": lo, "end": hi}

# Стало:
return {"units": "%lthr", "start": lo, "end": hi}
```

### Почему
- В API Intervals.icu объект целевого диапазона пульса с ключами `{"value": ..., "end": ...}` интерпретируется как целевая зона с привязкой к локальным зонам устройства (Lap-HR / zone-mapped target). При экспорте тренировки в FIT-файл для часов Garmin такой шаг привязывается к границам пульсовых зон самих часов, из-за чего коридоры обрезались под собственные зоны Forerunner (Z1–Z5), а не под рассчитанный диапазон.
- Использование пары ключей `{"start": ..., "end": ...}` переключает экспорт Intervals.icu в режим коридора мгновенного пульса (Instant-HR corridor / custom target boundaries). В этом случае Intervals.icu вычисляет точные абсолютные значения ЧСС на основе заданного процента от LTHR атлета (LTHR = 172) и передает точный коридор в Garmin Connect / FIT, благодаря чему часы отображают именно запланированный диапазон пульса.
