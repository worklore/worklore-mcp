# Исправление кеширования

В `bot.py` разделил системный промпт на два блока. Постоянные инструкции идут первыми и имеют `cache_control: ephemeral`; профиль спортсмена, дата и долговременные факты идут вторым блоком без маркера кеша. После `save_fact` обновляется только второй блок, поэтому запись факта не меняет кешируемый префикс инструкций.

Добавил в постоянный блок правила применения фактов. Это также увеличивает стабильный префикс: по `logs/usage.jsonl` прежний полный префикс был около 1024 токенов, и после отделения профиля одних исходных инструкций могло быть недостаточно для кеширования. Выбор инструментов по ключевым словам не менял. При смене набора инструментов кеш всё ещё может промахнуться, поскольку инструменты входят в префикс запроса перед системным промптом.

Добавил `test_cache.py`: он имитирует вызов `save_fact` и проверяет, что следующий запрос видит новый факт, а кешируемый блок и набор инструментов остаются прежними. Локально `python3 -m unittest -v test_cache.py` проходит. Реальные показатели `cache_read_input_tokens` не проверял: для этого потребовался бы вызов внешнего API, запрещённый условием задачи.
