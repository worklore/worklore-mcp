# Реализация событий аналитики

В соответствии со спецификацией в `docs/EVENTS.md` были добавлены события аналитики с использованием обёртки `Analytics.capture(...)`:

### 1. Экран регистрации (`lib/screens/registration_screen.dart`)

- `registration_email_started`: отправляется при начале ввода email пользователя (когда поле перестаёт быть пустым; отправляется единожды за ввод, данные email/PII не передаются).
- `registration_phone_started`: отправляется при начале ввода номера телефона (когда поле перестаёт быть пустым; отправляется единожды за ввод, данные телефона/PII не передаются).
- `loan_amount_changed`: отправляется при изменении значения слайдера суммы кредита с параметром `amount` (целое число: `int`).
- `terms_accepted`: отправляется при установке чекбокса согласия с условиями (`terms == true`).
- `registration_continue_tapped`: отправляется при нажатии на кнопку «Continue» с параметрами `amount` (целое число: `int`) и `terms` (`bool`).

### 2. Экран списка предложений (`lib/screens/offer_screen.dart`)

- Виджет `OfferScreen` преобразован в `StatefulWidget` с подключением `ScrollController` к `ListView.builder`.
- `offers_scrolled`: отправляется слушателем скролла при изменении смещения с параметром `offset` (число с плавающей точкой: `double`).
