# Исправление генератора тренировок (gen.py)

### Что изменили
В функции `hr_target` файла [`gen.py`](file:///tmp/h-PofJWt/gen.py) ключ нижней границы целевого диапазона пульса заменён с `"value"` на `"start"`:

```python
# Было:
return {"units": "%lthr", "value": lo, "end": hi}

# Стало:
return {"units": "%lthr", "start": lo, "end": hi}
```

### Почему это произошло и как работает исправление
1. **Причина проблемы:**
   При экспорте структурированной тренировки в Garmin через Intervals.icu структура `{"units": "%lthr", "value": lo, "end": hi}` интерпретируется как зональный/Lap-HR таргет (zone-mapped target). В этом режиме часы Garmin сопоставляют переданное значение со своими собственными внутренними границами зон пульса (хранящимися на часах) и обрезают/привязывают диапазон к краям конкретной зоны часов (например, 118–137, 137–151, 151–162 вместо запланированных коридоров).

2. **Результат исправления:**
   Использование пары ключей `{"start": lo, "end": hi}` переключает экспорт Intervals.icu в FIT-файл в режим точного коридора текущего пульса (Instant-HR corridor). В этом режиме Intervals.icu вычисляет абсолютные значения пульса (в bpm) по формуле от настроенного в сервисе LTHR (172 bpm) и передаёт точный целевой коридор (117–129, 151–160, 129–141, 112–124 bpm), предотвращая привязку к локальным пульсовым зонам часов Garmin.
