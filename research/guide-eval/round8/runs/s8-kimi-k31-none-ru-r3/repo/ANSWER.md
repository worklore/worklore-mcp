# Что изменено

Причина лишнего списания: `build_system()` помещала статические инструкции и контекст спортсмена, включая долговременные факты, в один кешируемый блок. После `save_fact` менялся весь блок, поэтому следующий запрос не мог переиспользовать кеш инструкций.

- В `bot.py` системный промпт разделён на два блока. Первый содержит только неизменные `INSTRUCTIONS` и сохраняет `cache_control: {"type": "ephemeral"}`. Второй содержит динамический `athlete_context()` и не имеет маркера кеширования.
- Теперь `save_fact` меняет только некешируемый контекст спортсмена; кешируемый префикс со статическими инструкциями остаётся неизменным.
- Описание кеширования в `README.md` приведено в соответствие с новым поведением.

Проверка: локально прогнан полный двухраундовый `reply()` с имитированным ответом API и вызовом `save_fact`. Подтверждено, что факт сохраняется, между раундами меняется только второй системный блок, а первый кешируемый блок совпадает полностью. Внешние API-вызовы не выполнялись.
