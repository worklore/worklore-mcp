# Изменение генератора

Генератор теперь берет `lthr_bpm` из плана, переводит границы `hr_pct` в целые уд/мин и записывает точный диапазон в текст каждого шага, включая шаги повтора. Для текущего плана это 117–129, 151–160, 129–141 и 112–124 уд/мин.

Структурированное поле `hr` убрано: по `readback/watch-notes.md` `%lthr` превращается на часах в границы их зон, а уже опробованные `bpm` и `start_bpm`/`end_bpm` давали неправильные значения. Текст шага сохраняет запланированный диапазон без этой подмены. Ограничение: часы не дадут оповещения о выходе за диапазон, поскольку структурированной пульсовой цели больше нет. Показ текста на самих часах после изменения не проверялся: данные никуда не отправлялись.

Проверка: `python3 gen.py plans/tempo-run.json` выдает ожидаемые четыре диапазона; `git diff --check` проходит.
