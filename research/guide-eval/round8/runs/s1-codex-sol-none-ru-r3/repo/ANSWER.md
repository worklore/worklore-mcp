# Исправление диапазонов пульса

В `gen.py` границы `hr_pct` теперь пересчитываются по `lthr_bpm` плана в целые удары в минуту. Генератор записывает в `workout_doc` центр (`value`) и половину ширины (`range`) коридора с `units: "bpm"`, а не пару `value`/`end` с `%lthr`. `end` описывает конечную точку цели, поэтому прежняя запись не задавала независимые нижнюю и верхнюю границы. Процентные цели также позволяли экспорту подменять коридор зоной часов.

В план добавлен явный `lthr_bpm: 172`, чтобы расчёт не зависел от автоматически определённого часами порога 168. Для текущего плана генератор выдаёт границы 117–129, 151–160, 129–141 и 112–124 уд/мин, включая шаги внутри повтора. Границы округляются по отдельности до ближайшего целого удара.

Локальная проверка сравнила все четыре рассчитанных коридора с ожидаемыми значениями из `readback/watch-notes.md`; `git diff --check` прошёл. Выгрузка на часы здесь не выполнялась, поэтому фактическое отображение после изменения ещё не проверено.
