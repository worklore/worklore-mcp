# Причина

`similarity()` в `src/app.py` вычисляла сходство через деление и возвращала `float`. При второй публикации `related()` помещала это значение в `similar[].score`, после чего `table.put_item()` отклонял всю запись: сериализатор DynamoDB не поддерживает Python `float`. Именно это показывает `TypeError: Float types are not supported. Use Decimal types instead.` в `logs/error.log:25`.

Первая публикация проходила, потому что таблица была пуста: `related()` возвращала пустой список, и ни одного `float` в записываемом элементе не было. Существующий тест проверял только этот путь с пустой таблицей.

# Исправление

- В `src/app.py:30` оценка сходства теперь сразу округляется до целого процента от 0 до 100. Промежуточные вычисления по-прежнему используют `float`, но наружу возвращается `int`, который DynamoDB принимает. Формат `score` задокументирован в `README.md`.
- В `tests/test_publish.py:27` добавлен регрессионный тест: сначала в таблицу записывается существующая история, затем через `handler()` публикуется вторая. Тест проверяет ответ `201`, обе записи, точную оценку сходства и тип `int`. `FakeTable` отклоняет `float` так же, как сериализатор boto3, поэтому прежняя реализация этот тест не прошла бы.

# Проверка

До исправления последовательные вызовы `handler()` дали `201`, затем `500` с воспроизведённым `TypeError`. После исправления:

- `python3 -m unittest discover tests` — 2 теста, все успешно;
- исходный сценарий двух последовательных публикаций — обе вернули `201`, оценка второй записи сохранена как `int`.

Проверка выполнена локально с `FakeTable`; в реальный AWS ничего не отправлялось и не деплоилось.

# Что пригодилось из заметки коллеги

Пригодились объяснение зависимости ошибки от непустой таблицы, рекомендация проследить вычисляемые значения с `/` и `round()`, преобразование оценки в целые проценты и регрессионный тест с предварительно заполненной таблицей. Вариант с `Decimal` не понадобился: целочисленный процент проще и сохраняет точность, достаточную для оценки сходства. Публикация в реальную таблицу не выполнялась, поскольку задача запрещает обращения к внешним сервисам, а существующий тестовый двойник уже воспроизводит нужную проверку типов DynamoDB.
