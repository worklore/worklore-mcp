# Почему nightly-review молчала

Задача **запускалась** (в `launchctl-print.txt`: `runs = 6`, `last exit code = 1`), просто падала и не могла об этом сообщить. Две причины друг за другом:

1. **`Not logged in · Please run /login`** (первая строка в `.err`). В окружении launchd нет `USER`, поэтому `claude` не находит логин в keychain и сразу падает. В `launchctl print` в `environment` есть только `PATH`.
   Исправление: в plist в `EnvironmentVariables` добавлен `USER=vk`.
2. **`read-only variable: status`** (`nightly-review.zsh:19`). В zsh `status` — встроенная переменная только для чтения, присваивание `status=$?` убивает скрипт. Оно стоит между вызовом агента и `notify.sh`, поэтому уведомление о сбое не отправлялось. Отсюда полная тишина.
   Исправление: переменная переименована в `rc`.

Дополнительно в скрипте:
- `claude` теперь запускается с `< /dev/null`, чтобы не ждать stdin.
- Длительность и код выхода пишутся в stderr-лог.
- Пустой файл результата теперь тоже считается сбоем, и приходит уведомление: код 0 при отсутствии результата не считается успехом.

## Что пригодилось из заметки коллеги
- `launchctl print` для проверки, что задача запускалась (runs / last exit code).
- Чтение лога stderr до теорий.
- Нельзя присваивать `status` в zsh, использовать `rc=$?`.
- `USER` в `EnvironmentVariables`.
- `< /dev/null` (промпт у меня передаётся аргументом, поэтому именно этот вариант, а не stdin).
- Логирование длительности и проверка реального результата, а не только кода выхода.

Не использовано: передача промпта через stdin (у меня промпт аргументом, и ошибки про него в логе нет); `launchctl kickstart` и принудительный сбой я не запускал (работаю только в этой папке).

## Что сделать вам
Скопировать plist и скрипт обратно в домашнюю директорию, затем `launchctl bootout gui/501/com.vk.nightly-review; launchctl bootstrap gui/501 ~/Library/LaunchAgents/com.vk.nightly-review.plist` и `launchctl kickstart -k gui/501/com.vk.nightly-review`. Проверить: приходит сообщение, файл `nightly-review-<дата>.md` свежий и непустой, время работы не несколько секунд. Затем один раз сломать скрипт и убедиться, что приходит уведомление о сбое.
Если `USER=vk` не подходит (имя пользователя другое), поправьте значение. Если «Not logged in» останется, вход `claude` нужно проверить вручную.
