# Причина сбоя

При первой публикации в таблице ещё нет историй, поэтому `similar` пустой и запись проходит. При второй публикации `similarity()` вычисляла `score` как `float`, а `publish()` помещала его в `similar` и передавала в `table.put_item()`. Сериализатор DynamoDB в `boto3` не принимает `float` (`Float types are not supported. Use Decimal types instead.`), поэтому обработчик возвращал 500. Каждая следующая публикация попадала в тот же путь.

# Исправление

`similarity()` теперь вычисляет и округляет оценку с помощью `Decimal`. Вложенные `similar[].score` сохраняются как поддерживаемые DynamoDB числа, включая нулевые оценки. Добавлен тест, который публикует три истории через обработчик, проверяет успешные ответы и тип сохранённых оценок.

Проверка: `python3 -m unittest discover tests` — 2 теста прошли.
