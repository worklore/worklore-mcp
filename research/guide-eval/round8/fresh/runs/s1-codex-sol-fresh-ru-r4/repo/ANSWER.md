# Исправление диапазонов пульса

В `gen.py` изменил представление цели `hr` в `workout_doc`: `value` теперь содержит середину диапазона, `start` — нижнюю границу, `end` — верхнюю. Например, запланированные 88–93% LTHR записываются как `value: 90.5, start: 88, end: 93`. Добавил проверку, что нижняя граница меньше верхней.

Раньше генератор записывал нижнюю границу в `value` и только верхнюю в `end`, без `start`. Это не задавало полный коридор в структуре цели. По `readback/watch-notes.md` часы показывали вместо запланированных чисел границы собственных зон. Новая запись сохраняет обе границы в полях цели и оставляет проценты LTHR, чтобы Intervals.icu мог пересчитать их по порогу спортсмена при экспорте.

Добавил `test_gen.py`: он проверяет форму цели и диапазоны всех шагов, включая повторения. `python3 -m unittest -v test_gen` и `git diff --check` прошли. Вывод генератора проверен локально. Фактическое отображение на часах не проверялось: для этого потребовалась бы отправка тренировки во внешний сервис, запрещённая условиями задачи.
